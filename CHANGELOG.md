# Changelog

## 1.3.0

First public release.

- Bar icon that appears while a USB stick, SD card or external drive is
  plugged in, with a popup per drive: size, mount point, used space, USB
  connection speed and live read/write speed.
- Open (mounting and unlocking first if needed) and Eject (unmount, lock
  encrypted volumes, power off).
- Names the programs keeping a drive busy when eject fails, and updates
  that live while the popup is open.
- Never lists or ejects the drive the running system uses.
- Settings: used space on the bar, connection line, transfer speed, eject
  notification.
- Missing tools are reported with the package to install.
